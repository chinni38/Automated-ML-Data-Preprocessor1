# Automated ML Data Preprocessor

## Week 5 Milestone

This project prepares a mixed customer churn dataset for downstream machine-learning model training.

### Dataset
- File: `customer_churn_dataset.csv`
- Rows: 1000
- Raw columns: 15
- Target: `Churn`
- Target encoding: `No = 0`, `Yes = 1`

### Techniques implemented

1. **Categorical Feature Encoding**
   - Uses `pandas.get_dummies()`.
   - Converts categorical columns such as Contract, InternetService, PaymentMethod, Gender, etc. into machine-readable numeric columns.

2. **Z-Score Feature Scaling**
   - Uses `StandardScaler`.
   - Numerical features such as Age, TenureMonths, MonthlyCharges and TotalCharges are standardized.
   - The scaler is fitted only on training data and then applied to test data to avoid data leakage.

3. **Train-Test Partitioning**
   - Uses `train_test_split(test_size=0.2, random_state=42, stratify=y)`.
   - 80% of the data is used for training and 20% for testing.

4. **Structured Artifact Export**
   - `processed/X_train.csv`
   - `processed/X_test.csv`
   - `processed/y_train.csv`
   - `processed/y_test.csv`

```bash

python preprocess.py
```

The script creates the `processed` folder and exports the four required train/test files for Week 6 model training.
